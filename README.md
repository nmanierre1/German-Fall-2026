### Electrical Supply

Germany's nominal supply is **230 V, 50 Hz**, with Type C/F plugs. A device labeled **100–240 V, 50/60 Hz** generally needs a compatible plug adapter rather than a voltage converter. Check the device label; a plug adapter does not change voltage. [Source: VDE](https://www.vde.com/topics-en/consumer-protection/power-supply-and-security-when-traveling).
